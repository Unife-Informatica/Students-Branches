# 1. first program
Ogni file sorgente (`.java`) deve ospitare una classe.
Per **compilare** un file devo lanciare il comando: `javac <nome_file>.java`
Questo genererà un file con il nome della classe (che deve essere uguale al nome del file) `<nome_file>.class`
Per **eseguilo** devo usare il comando: `java <nome_file>` (senza includere l'estensione `class`)
