### Velocità scalare
$$ v_{\text{scalare, media}} = \frac{d}{\delta t} $$
La velocità media è una misura di quanto rapidamente un punto si muove


### Velocità media
Misura della rapidità di variazione della posizione di un corpo
$$\Delta\vec{x} = \vec{x_{f}} - \vec{x_{i}} = (x_{f} - x_{i})\hat{i}$$
Spostamento:
$$v_{x, media} = \frac{\Delta x}{\Delta t} = \frac{x_{f} - x_{i}}{t_{f} - t_{i}}$$
Unità di misura $\frac{x}{s}$


### Velocità instantanea 
$$ v_{x} = \lim_{ \Delta t \to 0 }{\frac{\Delta x}{\Delta t}} = \frac{dx}{dt}$$
Derivata di $x$ rispetto a $t$


### Accelerazione media
 $$ a_{x, media} = \frac{\Delta v_{x}}{\Delta t} =   \frac{v_{x_{f}} - v_{x_{i}}}{t_{f} - t_{i}} $$
Grandezza vettoriale: misura della rapidità di variazione della velocità di un corpo


### Accelerazione istantanea
$$a_{x} = \lim_{ \Delta t \to 0 }{\frac{\Delta v_{x}}{\Delta t}} = \frac{dv_{x}}{dt}$$
poiché:
$$v_{x} = \frac{dx}{dt}$$
$$a_{x} = \frac{dv_{x}}{dt} = \frac{d}{dt}\left( \frac{dx}{dt} \right) = \frac{d^2x}{dt^2}$$


### Moto rettilineo uniforme
$$x_{f} = x_{i} + v_{x}t$$
$$v_{x} = \lim_{ \Delta t \to 0 }\frac{\Delta x}{\Delta t} = \frac{dx}{dt} = \text{costante}$$
$$a_{x}(t) = \frac{dv_{x}(t)}{dt} = 0$$
