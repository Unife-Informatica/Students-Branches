1. Nel C esistono due metodi per passare un valore: il passaggio per valore ed il passaggio per riferimento. Nel passaggio per valore viene effettivamente passato il valore contenuto all'interno della variabile creando così un effettiva copia, mentre nel passaggio per riferimento viene passato l'indirizzo di memoria dentro cui è contenuto il valore della variabile. La funzione avrà così la possibilità di accedere all'area di memoria originale e modificare il valore.

2. N matricola: 205330 --> output: 0 2 0

3. Una **struct** è un tipo di dato che permette di raggruppare variabili di tipi diversi. Ogni membro della struct occupa una parte separata della memoria, e quindi i membri della struct possono essere accessibili indipendentemente l'uno dall'altro. Mentre tutti i membri di una **union** condividono lo stesso spazio di memoria. Questo significa che, in qualsiasi momento, una union può contenere solo un membro alla volta.
