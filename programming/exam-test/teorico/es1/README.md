1. L'**iterazione** è un concetto che indica l'esecuzione ripetuta di un blocco di istruzioni in un programma, fino al soddisfacimento di una condizione specifica. In altre parole, un'iterazione è una ripetizione di un'operazione o di un insieme di operazioni. <br/>
In C, un'iterazione è utilizzata quando si vuole eseguire un'azione o una serie di azioni più volte, ad esempio per attraversare un array o ripetere una parte del codice finché non viene raggiunta una certa condizione. L'iterazione può essere implementata attraverso diverse strutture di controllo di flusso.
